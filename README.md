# IS.TOQUE — protótipo navegável

Protótipo das telas do IS.TOQUE, um sistema de gerenciamento de estoque para microempresas, com foco em restaurantes.

**Acesse:** https://erezende544.github.io/istoque-prototipo/

O protótipo é um arquivo HTML único (`index.html`) com dados de demonstração. Ele roda inteiro no navegador: nada do que é cadastrado nele é enviado para um servidor.

Trabalho Interdisciplinar do curso de Análise e Desenvolvimento de Sistemas da PUC Minas.
